Adds a custom taxonomy to categorize media items and provides filters in the media library (list and grid/modal views).

== Description ==

This plugin allows you to organize your WordPress media library by assigning categories to your attachments. It then provides convenient dropdown filters to find media by these categories, both in the main Media Library screen and in the media upload modal.

== Installation ==

1. Upload the `wp-media-categories` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Go to Media > Media Categories to add your categories.
4. Assign categories to your media items when uploading or editing them.
5. Use the new filter dropdowns in the Media Library.
